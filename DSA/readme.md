## 🧠 Quick Technique Reference

| Technique | Key Idea | Time Complexity |
|-----------|----------|-----------------|
| HashMap / HashSet | O(1) lookup, frequency count | O(n) |
| Two Pointers | Left + right converge | O(n) |
| Sliding Window | Expand/shrink a window | O(n) |
| Prefix Sum | Precompute cumulative values | O(n) |
| Kadane's Algorithm | Track local & global max | O(n) |
| Greedy | Locally optimal choice | O(n) or O(n log n) |
| Sorting | Sort to simplify | O(n log n) |
| Math / XOR | Use arithmetic properties | O(n) |
| Matrix Traversal | Navigate 2D grid patterns | O(m×n) |
| Expand Around Center | Expand from each index | O(n²) |
| Bucket Sort | Index-based frequency buckets | O(n) |
