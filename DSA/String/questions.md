# String Interview Questions (Easy Level)

This document contains 20 beginner-friendly string interview questions that cover the most common string manipulation patterns asked in coding interviews.

---

# 1. Reverse a String

## Problem
Given a string `str`, return the string in reverse order.

### Example 1

**Input**
```text
hello
```

**Output**
```text
olleh
```

### Example 2

**Input**
```text
JavaScript
```

**Output**
```text
tpircSavaJ
```

# 14. Longest Substring Without Repeating Characters

# Practice Goals

Try to solve every problem:

- Without using built-in helper functions initially.
- Aim for **O(n)** time complexity whenever possible.
- Explain your approach before writing code.
- Test your solution with edge cases.
